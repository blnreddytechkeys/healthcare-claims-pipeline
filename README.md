# Healthcare Claims Data Pipeline

End-to-end data pipeline for processing healthcare claims data using Python and SQL.

## Project Overview
This project demonstrates a simple ETL pipeline for healthcare claims data:
- Extract data from CSV
- Clean and transform using Python (Pandas)
- Load and analyze using SQL

## Tech Stack
- Python 3.10+
- Pandas
- SQL
- GitHub
