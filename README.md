# Healthcare Claims Data Pipeline

A simple yet complete **ETL pipeline** for processing healthcare claims data using Python and SQL.  
This project demonstrates data extraction, cleaning, transformation, and basic analysis — built as part of my transition into Data Engineering.

---

## Project Overview

This repository contains an end-to-end data pipeline that:

- Extracts healthcare claims data from a CSV file
- Cleans and transforms the data using Python (Pandas)
- Performs basic analytical queries using SQL
- Follows a clear and modular project structure

The pipeline is designed with **healthcare domain** context (claims, members, providers, diagnosis codes) to reflect real-world scenarios.

---

## Features

- Extract data from CSV
- Data cleaning & transformation (date conversion, status standardization, duplicate removal)
- High-value claims identification
- SQL-based analysis (status summary, provider performance, high-value claims)
- Clean and scalable folder structure
- Ready for future enhancement with Azure Data Factory & Databricks
